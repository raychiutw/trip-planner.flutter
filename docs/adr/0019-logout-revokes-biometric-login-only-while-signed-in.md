# 登出即撤銷；生物辨識登入只在登入期間有效

取代 [ADR-0017](0017-biometric-login-stays-on-device.md)，並取代 [ADR-0018](0018-web-login-page-biometric-entry.md) 中「設定頁開啟與關閉都要重新驗證密碼」一條。做法比照 my-money iOS（raychiutw/my-money.ios#359）。需求見 trip-planner spec #1743。

## Decision

- **登出一律撤銷並清除**：不論有沒有開啟生物辨識登入，登出都呼叫伺服器撤銷登入憑證，並清掉這支手機上的憑證與 DPoP 金鑰。撤銷失敗（離線、伺服器錯誤）時本機仍清除，登出照常完成。不再有「登出但保留憑證」，「忘記這支手機」併入登出後移除。
- **生物辨識登入只在登入期間有效**：開啟後，冷啟動讀憑證時跳生物辨識，通過就 refresh 並進「我的行程」；取消或失敗停在歡迎頁，按「登入」再驗一次；憑證不能用（refresh 被拒、生物特徵變更使金鑰失效）才清除並開 web 登入頁。登出後要重新輸入帳密。
- **只接受生物辨識**：iOS 以 `biometryCurrentSet`、僅限這台裝置；Android 以 BIOMETRIC_STRONG 並在新增或更改指紋時失效。都不能改用裝置密碼。沒有生物辨識的手機不顯示這個功能，憑證照一般方式（裝置密碼保護）保存。
- **輪替保留保護等級**：refresh 輪替寫入新憑證時保留原保護等級，寫入不需要驗證，使用中不會跳生物辨識。驗證期間若登入狀態已改變（登出、過期、換帳號），驗證回來後不得把舊憑證寫回。
- **開啟的入口**：web 登入頁的生物辨識鈕（沿用 ADR-0018：照常登入，導回時由 server 帶旗標，App 直接驗證一次，取消則照一般方式登入）；或設定頁開關，驗證一次生物辨識即開啟。
- **關閉**：設定頁開關關閉時改回一般保存，不登出、不驗證。
- **App 鎖**：冷啟動已為讀憑證驗證過生物辨識，就不再上 App 鎖；開啟生物辨識登入後不再詢問是否開啟 App 鎖。離開前景後回來的 App 鎖照舊。
- **重新驗證模式整套移除**：api 的 `prompt=login`（含單獨使用）、`biometric_intent` 的 `disable`、`expected_account`、`reauth_account_mismatch`，web 授權頁的重新驗證畫面，App 的重新驗證流程，全部刪除。web 登入頁按鈕帶出的 `enable` 旗標保留。
- **既有保留憑證的遷移**：更新後第一次啟動，若是「已登出卻有保留的憑證」，直接刪除本機憑證與金鑰，不驗證、不撤銷；伺服器端那份最多 30 天後失效，也可從 web 的已登入裝置撤銷。
- **歡迎頁保留**：未登入時顯示歡迎頁，按「登入」才開瀏覽器，不自動開系統登入視窗。

## Considered Options

- **登出保留憑證（ADR-0017）**：登出後可直接用 Face ID 回來。拒絕：owner 認為登出卻不作廢憑證不合理，登出就要真的登出。
- **登入後再詢問要不要開啟生物辨識**：拒絕：多一步打斷；入口放在 web 登入頁的按鈕。
- **沒開啟過就不顯示 web 登入頁的按鈕**：拒絕：使用者第一次就找不到入口。
- **passkey（ADR-0016）**：拒絕：後端要存憑證；沒建立過時 iOS 會跳「掃描行動條碼」，使用者看不懂。
- **沒登入時直接開系統登入視窗（my-money 做法）**：拒絕：Android 授權分頁被關掉後自動重開不穩；歡迎頁有隱私權政策與帳號刪除說明入口。
- **設定頁開關要重新輸入密碼（ADR-0018）**：拒絕：登出已撤銷，留在手機的憑證只服務目前這次登入，用密碼守開關的價值下降，且讓 api、web、App 多一整套流程。

## Consequences

- 登出後伺服器與手機都乾淨；代價是登出後回來一定要輸入帳密。
- 憑證與 DPoP 金鑰仍一起保存、一起刪除（[ADR-0015](0015-dpop-key-bound-tokens.md)），回到 ADR-0015 原本「登出時一併刪除」的字面規則。
- api、web、App 三邊同時移除重新驗證模式並一起部署；舊版 App（0.41.x）的設定頁開關在部署後會失效。只有 owner 在測，接受。
- 只接受生物辨識、生物特徵變更即失效、冷啟動只驗一次等原生行為無法在自動測試驗證，需要 iOS 與 Android 真機驗證。

## 為何難以逆轉

使用者會預期「登出後要重新輸入密碼」與「冷啟動刷一次臉就進來」；api 移除重新驗證模式後，要恢復設定頁的密碼驗證得三個倉庫一起加回來。
