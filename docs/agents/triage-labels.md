# Triage labels

Matt skills 使用五種標準 triage 角色。本表定義它們在此 repo 的實際 label。

| Matt skill 角色 | GitHub label | 用途 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待 maintainer 評估 |
| `needs-info` | `needs-info` | 等待回報者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交由 agent 執行 |
| `ready-for-human` | `ready-for-human` | 需要人工處理 |
| `wontfix` | `wontfix` | 決定不處理 |

Skill 提到角色時，使用本表對應的 GitHub label。若日後 repo 改用不同命名，只需修改右欄。
