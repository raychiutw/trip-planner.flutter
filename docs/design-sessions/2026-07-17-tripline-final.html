驗收規則

  • Root tab 固定四項：聊天／行程／地圖／收藏；可見高度 44pt，帳號固定右上圓形 avatar。
  • DAY selector 完全依定版圖：`地圖／行程 action | DAY…`；不顯示「總覽」。外膠囊 44pt／22pt radius、active thumb 34pt／17pt radius、DAY 標籤採 12pt semibold，整段可水平滑動。
  • 返回、關閉、帳號與功能 action 共用 44pt Liquid Glass 圓形元件；帳號 avatar 顯示帳號首字元；同列兩個以上圓形按鈕固定保留 8pt 間距。
  • 筆記在右上功能區；行程切換、帳號與功能選單的內容頁共用 93% 高度 bottom sheet，第一層有 drag indicator 與右上 44pt 關閉鈕；子頁共用 sheet 內導覽殼，左上返回、右上關閉整個 sheet。
  • 展開功能頁使用共用 GlassAppBar，Title 3（20pt）標題置中並緊接 drag indicator；accordion 使用共用暖白／中性深色 Liquid Glass 展開區塊。
  • 行程每日顯示明確標示的天氣示意，不顯示重複的每日飯店摘要卡。
  • Light 使用暖白色階；Dark 使用中性深色。DAY 使用 22pt blur；POI dock 使用 28pt blur＋高亮 rim；POI 卡使用半透明內容 surface，避免巢狀 blur 造成雙層玻璃失真。
  • POI dock 完全依定版圖：卡片寬度為軌道 80%，第一卡靠左且下一卡露出約 25%；底部頁碼圓點 active 為 accent 短膠囊。卡片採編號圓章、停留序號、名稱、時間摘要與右側導航圓鈕；與 root tab 間距 4pt。
  • Mobile 使用 `google_navigation_flutter` map-only `GoogleMapsMapView`，Google 原生 POI 可點擊並由使用者主動外開 Google Maps；每日 zoom 固定 12。AI composer 維持既有送出、語音、附件與狀態處理，只套用定版位置與外觀。
  • 每頁至少一個低比例 Tripline accent，限互動 tint、選取狀態或主要動作；不可用色彩取代文字／圖示語意。行程列表與內容頁共用 `TpMoreMenuButton`；觸發鈕與面板共用 primaryContainer 玻璃，Light 選項使用深色 onPrimaryContainer、Dark 使用 primary，禁止使用純黑。字體使用 HIG semantic text styles 與 Dynamic Type。
